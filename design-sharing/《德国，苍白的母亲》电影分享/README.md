## 内容简介

本次分享以赫尔玛·桑德斯-布拉姆斯执导的 1980 年电影《德国，苍白的母亲》为核心，从女儿的视角重新审视战争、家庭与女性经验。内容围绕历史背景、人物关系、战时与战后性别秩序、影片结局以及导演的家庭经验展开。

## 核心内容

- 以 1933—1950 年的历史坐标理解人物命运。
- 对比 Lene 在战时与战后拥有的决定权。
- 通过关键场景、视听语言和结局分析电影的核心表达。
- 讨论个人创伤、家庭秩序与国家历史之间的关系。
