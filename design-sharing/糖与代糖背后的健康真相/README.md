第01页｜封面：0糖、0卡、0负担？
核心问题： 用代糖替代普通糖之后，健康负担是否真的消失？

普通可乐与无糖可乐具有相近的甜味体验，但糖含量和热量明显不同。本次分享围绕三个问题展开：糖进入人体后做了什么；代糖能够解决哪些由糖引起的问题；替代之后还有哪些健康风险与不确定性。

从便利店中的普通可乐与无糖可乐切入，结合人体代谢机制、科学研究及食品标签，建立可以用于日常饮料选购的判断方法。

第一章｜甜蜜的诱惑
<a id="p02"></a>
第02页｜为什么人类喜欢吃甜食
- 生存与演化： 原稿从远古食物匮乏的环境解释甜味偏好：甜味常提示成熟果实和能量来源，苦味可能提示某些不宜摄入的物质。
- 大脑奖励机制： 摄入甜味食物与大脑奖励系统、多巴胺信号相关，愉悦体验可以强化对甜食的偏好。
- 环境变化： 过去大量糖分较难获得，现代奶茶、甜点和含糖饮料随手可得。原有偏好与现代高糖食品环境相遇，可能增加过量摄入的机会及代谢负担。
- 生活案例： 工作压力大时通过甜点获得短暂满足。原页使用 stressed 与 desserts 字母倒序的趣味梗及甜点图片，并嵌有视频素材。
核心结论： 喜欢甜味可以从生存适应和奖励机制理解，但现代食品环境使这种偏好更容易转化为过量摄入。
原稿待核实：甜味不保证食物安全，苦味也不必然代表有毒；“刻在基因里”和“多巴胺释放”是简化解释，原页未列具体研究来源。该页演讲备注重复了第03页的可乐糖量案例，已归入第03页。

第03页｜一罐可乐，究竟藏着多少糖？
以每100 mL含糖约10.6 g的普通可乐为示例：
指标	数值
饮料容量	330 mL
糖含量	约35 g
方糖等值（每块5 g）	约7块
来自糖的能量	约140千卡

原稿待核实：页面还将140千卡类比为约150 g米饭，但未注明米饭种类、含水量及营养数据来源，不宜作为固定换算。

<a id="chapter-2"></a>
第二章｜糖的另一面
<a id="p04"></a>
第04页｜人体需要糖，为什么又要少吃糖？
葡萄糖的产生、利用与储存
以一碗米饭为例：

淀粉类主食摄入 → 淀粉消化分解为葡萄糖 → 小肠吸收入血 → 胰岛素等激素参与调节 → 组织供能或肝脏、肌肉糖原储存

米饭、面条及薯类等食物中的淀粉可以提供葡萄糖。葡萄糖是人体重要的能量来源，正常餐后血糖升高与胰岛素分泌属于生理反应。
为什么仍需控制糖摄入
身体可以通过主食等食物获得葡萄糖，不需要特意通过白砂糖、甜点或含糖饮料补充添加糖。长期过量摄入添加糖，尤其是在正常饮食之外摄入含糖饮料，可能增加总能量及体重管理、代谢健康方面的风险。

核心结论： 人体需要葡萄糖，不等于人体必须摄入添加糖。不能将胰岛素简单视作“致胖激素”，也不能将暂时未利用的葡萄糖等同于立即形成的脂肪；长期能量过剩是重要因素。
原稿待核实：页面补充口语中“主食慢慢、匀速分解”“存不下就变肥肉”“血糖坐过山车”等属于简化表述，不能视为所有主食的固定消化曲线或必然代谢结果。

原稿来源： WHO健康饮食资料；《中国居民膳食指南（2022）》。

<a id="p05"></a>
第05页｜吃苹果和喝苹果汁，为什么不一样？
比较维度	内在糖（以完整苹果为例）	游离糖（以苹果汁为例）
食物结构	糖存在于完整水果的细胞结构内	榨汁破坏部分细胞结构
其他成分	同时摄入膳食纤维、水分、维生素等	加工和过滤可能减少部分纤维
摄入方式	需要咀嚼	可以快速饮用
摄入量与饱腹感	完整水果通常更有利于限制短时间摄入量	可能在较短时间内饮用多个水果所含的糖


WHO将食品制作中添加的糖，以及蜂蜜、糖浆、果汁和浓缩果汁中天然存在的糖归为游离糖。牛奶中天然存在的乳糖不属于游离糖，但也不能简单等同于完整水果细胞中的内在糖。

生活案例： 吃下几个完整苹果与喝下由几个苹果榨成的果汁，摄入体验不同。区别并非糖分子突然发生变化，而是食物基质、摄入速度、摄入量和饱腹感可能不同。

核心结论： 判断糖的营养意义，需要结合其所在食物的整体结构，而非只看糖本身。
原稿待核实：原页将内在糖概括为“升血糖慢”、游离糖概括为“升血糖快”。该说法不能作为绝对分类规则，具体反应还与食物、加工方式和摄入量有关。

原稿来源： WHO《成人和儿童糖摄入指南》，2015年。

<a id="p06"></a>
第06页｜每天到底能摄入多少糖？
WHO游离糖建议
游离糖摄入量应控制在每日总能量的10%以下，进一步降低到5%以下可能获得额外健康益处。以每日摄入2,000千卡为计算示例：
原PPT图表项目	游离糖参考量
5%能量参考	25 g
一罐330 mL普通可乐	约35 g
10%能量参考	50 g


计算：`2,000 × 5% ÷ 4 = 25 g`；`2,000 × 10% ÷ 4 = 50 g`。

一罐35 g糖的普通可乐超过25 g的严格参考目标，但没有超过50 g的10%参考值。该换算以2,000千卡饮食为例，并非所有人的固定需求。
中国居民膳食指南
《中国居民膳食指南（2022）》建议添加糖每天不超过50 g，最好控制在25 g以下。中国指南此处采用“添加糖”口径，WHO采用“游离糖”口径，两者不能完全等同；限制的并非所有主食中的碳水化合物。

原稿来源： WHO糖摄入指南（2015）；《中国居民膳食指南（2022）》。

第07页｜糖吃多了，身体究竟会发生什么变化？
健康问题	原PPT介绍的机制或研究关联
体重增加与肥胖	长期能量摄入超过消耗，多余能量可能以脂肪形式储存，体重和内脏脂肪可能增加。
血糖与胰岛素抵抗	含糖饮料增加糖负荷；长期高能量摄入、体重增加等因素参与胰岛素抵抗的形成。糖尿病不能简单归因于吃糖。
脂肪肝	肝脏处理多种营养素；长期能量过剩可能增加脂质合成与肝内脂肪积累，与脂肪肝风险相关。
龋齿（蛀牙）	口腔细菌利用糖产酸，反复酸性环境使牙齿脱矿，长期可能形成龋洞。
心血管健康	长期高摄入含糖饮料与部分心血管疾病风险升高相关，体重、血脂、血压及整体代谢状态共同参与。


原稿备注强调，体重、遗传、运动和整体饮食也会影响上述健康风险，不能把所有疾病归因于糖。

核心结论： 应重点关注高频、长期、过量的摄入模式，尤其是额外能量摄入，而不是将偶尔喝一罐饮料直接等同于患病。

原稿来源： WHO；CDC含糖饮料健康资料；含糖饮料与代谢疾病相关系统综述（原页未列出具体文献）。

<a id="p08"></a>
第08页｜糖真的会让皮肤老得更快吗？
糖化反应
葡萄糖等还原糖与蛋白质发生非酶促反应，经过中间反应过程，可形成晚期糖基化终末产物（Advanced Glycation End Products，AGEs）。
对皮肤的潜在影响
AGEs参与胶原蛋白交联，可能改变纤维的排列和力学性质，使组织弹性受到影响。这是皮肤老化研究中的机制之一。原稿用“有弹性的橡皮筋被粘住”比喻胶原纤维发生交联后的结构变化。

部分研究还支持高升糖负荷饮食与痤疮存在关联，但激素、遗传等因素同样重要。日晒、年龄、遗传和吸烟也参与皮肤老化过程。

核心结论： 糖化机制存在，但不能将皮肤衰老简单归因于糖，不能推算喝一罐可乐会老几岁，也不能承诺戒糖逆龄。
原稿待核实：页面附加文字提到皮肤变黄、松弛、皱纹提前、痘印难消，并推测经常吃糖但皮肤状态好的人只是尚未显现损伤。原页未提供足以证明这些具体个体后果的证据，不应将其视为确定结果。

原稿来源： AGEs与皮肤老化相关综述，PubMed 23467327、35646963。

<a id="p09"></a>
第09页｜为什么含糖饮料尤其值得注意？
含糖饮料不需要咀嚼，通常可以较快饮用，也容易出现在三餐之外。正常进食过程中，咀嚼、胃排空和肠道信号会逐渐带来饱腹感；饮料热量的饱腹感及食欲补偿程度存在个体差异。

生活案例： 午餐已经摄入能量，回到工位后再喝一罐普通可乐，相当于额外摄入约140千卡来自糖的能量（若没有减少其他摄入）。喝下140千卡，不代表下一餐会自动少吃140千卡。

核心结论： 不仅固体食物需要计算热量，饮料同样需要纳入全天能量摄入。
原稿待核实：页面中的“几乎不带来饱腹感”“不顶饱”“伤害来得又快又隐蔽”属于过度概括；原稿备注已说明个体差异，不能由此推断每个人都必然发胖。

原稿来源： WHO健康饮食资料；含糖饮料与能量摄入相关研究（未列具体文献）。

<a id="chapter-3"></a>
第三章｜代糖的诞生
<a id="p10"></a>
第10页｜代糖：为什么没有糖，也能产生甜味？
人体味觉细胞具有参与甜味识别的受体，其中T1R2和T1R3组成的甜味受体是原稿介绍的关键结构。蔗糖及某些甜味剂能够与甜味感受系统相互作用，触发神经信号，让大脑感受到甜味。

信号传递过程： 甜味物质 → 甜味受体 → 神经信号 → 大脑感知甜味。

通俗类比： 甜味受体像门铃或锁，普通糖与部分代糖都可以触发甜味信号。但门铃响并不代表送来的物质及能量相同。该比喻不代表真实受体的机械结构。

核心结论： 甜味感知与糖、能量摄入是不同的过程，感觉很甜不代表摄入了很多糖。

原稿来源： T1R2/T1R3味觉受体研究综述；FDA甜味剂资料。

<a id="p11"></a>
第11页｜为什么有的代糖比白糖甜600倍？
相对甜度比较的是特定条件下不同物质达到相似甜味所需要的浓度。不同分子结构及其与甜味受体相互作用的方式，会导致所需浓度存在明显差异。
甜味物质	原PPT图表相对甜度（蔗糖=1）
蔗糖	1倍
阿斯巴甜	约200倍
安赛蜜	约200倍
三氯蔗糖	约600倍


理想化等甜换算： 6 g 蔗糖 ÷ 600 = 0.01 g 三氯蔗糖，即约10 mg。该计算用于理解数量级差异，实际食品配方还受浓度、温度、食品组成和余味等因素影响，不能直接按这一比例替换。

原PPT使用线性刻度柱状图，因此蔗糖的1倍柱形几乎不可见，这反映数量级差异；若改用对数坐标或断轴，必须明确标注。

核心结论： 600倍描述相对甜度，并不代表600倍热量、血糖负荷或毒性。

原稿来源： FDA甜味剂资料。

<a id="p12"></a>
第12页｜代糖家族，不同甜味剂到底有什么区别？
类别	代表物质	甜度与实际用量	能量特点	注意事项
人工合成高甜度甜味剂	阿斯巴甜、安赛蜜、三氯蔗糖	甜度高，用量很少	实际配方中通常能量贡献极低	安全性应逐一评价；苯丙酮尿症患者需避免或限制阿斯巴甜
植物来源高甜度甜味剂	甜菊糖苷、罗汉果甜苷	甜度高，用量较少	实际配方中通常能量贡献极低	天然来源不自动等于安全，同样存在使用规范
糖醇	赤藓糖醇、木糖醇、山梨糖醇	甜度通常接近或低于蔗糖，用量相对较大	因物质而异；赤藓糖醇能量很低，木糖醇可提供能量	部分糖醇摄入较多可能引起腹胀、排气、腹泻


高甜度甜味剂像浓缩的甜味调配工具；糖醇在食品中还可能承担体积、质构和口感方面的作用。人工或植物来源属于来源维度，高甜度甜味剂与糖醇属于性质及用途维度，不能理解为三个完全独立的科学分类阵营。

核心结论： 不存在绝对最好的代糖类别，应结合具体物质、摄入剂量和食品用途判断。

原稿来源： FDA甜味剂资料；GB 2760《食品安全国家标准 食品添加剂使用标准》。

<a id="p13"></a>
第13页｜为什么无糖饮料常常使用多种代糖？
不同甜味剂的起甜速度、甜味峰值、持续时间和余味有所差异，个别甜味剂在较高浓度下还可能产生苦味或其他后味。食品研发人员通过两种或多种甜味剂复配，调整甜味的时间曲线与整体口感，使其更接近目标风味。

产品案例： 部分市场的无糖可乐使用阿斯巴甜与安赛蜜复配；原页展示的配料案例还列有蔗糖素（即三氯蔗糖）。不同品牌、国家和版本的配方可能不同，应以实际配料表为准。

核心结论： 无糖饮料的甜味通常是配方设计的结果，而不只是某一种甜味剂的作用。

原稿来源： 真实产品包装及配料表；食品配方与感官研究（未注明具体文献）。

<a id="p14"></a>
第14页｜换成代糖，我们究竟减少了什么？

明确减少的负担	仍然存在的问题

<a id="p15"></a>
第15页｜每天换一罐无糖可乐，一年能瘦多少斤？
理论能量差计算
假设每天将一罐约140千卡的普通可乐替换为近乎零热量的无糖可乐，且其他条件不变。
计算阶段	数值
每日饮料能量差	约140千卡
每年饮料能量差	约51,100千卡
静态能量等值	约6.6 kg（13.3斤）


计算：`140 × 365 = 51,100 千卡`；`51,100 ÷ 7,700 ≈ 6.6 kg`，按未四舍五入数值换算约13.3斤。
65 kg与100 kg的人会有什么区别
两个人替换同样一罐饮料，减少的饮料能量相同，都是约140千卡/天。实际减重可能因为基础能量消耗、补偿性进食、活动量、身体组成和体重变化引起的能量消耗调整而不同。

生活案例： 换成无糖可乐后，如果又因为节省了热量而多吃一块蛋糕，原本减少的部分能量可能被补偿回来。

核心结论： 13.3斤仅为简化静态能量等值，不是一年后的真实减重预测。个体减重需要明确假设并使用动态体重模型，不能仅根据初始体重直接推算；实际干预效果应参考人体研究。

原稿来源： 7,700千卡/kg静态能量换算；NIH/NIDDK Body Weight Planner。

<a id="chapter-5"></a>
第五章｜甜蜜的争议
<a id="p18"></a>
第18页｜为什么不建议依靠代糖长期减肥？
2023年，WHO发布非糖甜味剂使用指南，提出有条件的建议：一般人群不应将非糖甜味剂作为长期控制体重或降低非传染性疾病风险的手段。

主要考虑因素：
- 短期随机对照试验支持替代含糖饮料可能带来小幅体重管理收益。
- 长期体重和慢性疾病结局的证据仍然不足。
- 长期观察性研究发现的风险关联可能受到混杂因素及反向因果的影响。
反向因果案例： 已经超重的人可能更主动选择无糖饮料。若观察到无糖饮料饮用者平均体重较高，不能直接认定是无糖饮料使其变胖；原有体重也可能影响饮料选择。这是解释观察性关联的一种可能路径，而不是所有关联的唯一解释。

适用范围： 该指南建议不适用于已患糖尿病的人群，不包括糖醇，也不是对各甜味剂毒理安全性的重新评价。本页含嵌入视频素材。

核心结论： 代糖可以作为替代工具，但不应成为长期健康管理的唯一依赖。

原稿来源： WHO《非糖甜味剂使用指南》，2023年。

<a id="p19"></a>
第19页｜阿斯巴甜可能致癌，还能放心喝吗？
2023年7月14日，WHO公布IARC与JECFA有关阿斯巴甜的评估结果。两类评估的目的不同：
机构	评估内容	原PPT列出的结论
IARC（国际癌症研究机构）	危害识别：是否可能致癌、相关证据强度	2B类，可能对人类致癌
JECFA（FAO/WHO食品添加剂联合专家委员会）	风险评估：具体摄入剂量下的健康风险	维持每日可接受摄入量（ADI）0—40 mg/kg体重/日


IARC的2B分类不是患癌概率，也不是致癌能力强弱排名。
ADI计算示例
成年人体重	按40 mg/kg体重/日计算的ADI上限
65 kg	2,600 mg/日
70 kg	2,800 mg/日
100 kg	4,000 mg/日


WHO假设案例：70 kg成人、每罐饮料含200—300 mg阿斯巴甜、没有其他阿斯巴甜摄入来源时，约需超过9—14罐此类饮料才会超过ADI。罐数随具体配方变化，不能应用于所有无糖可乐，也不是饮用建议。

核心结论： 评价甜味剂安全性需要结合具体物质、摄入量、暴露条件与证据，而非仅依据“可能致癌”分类。

原稿来源： WHO / IARC / JECFA，2023-07-14阿斯巴甜危害与风险评估结果。

<a id="p20"></a>
第20页｜代糖影响肠道菌群，会给身体带来什么后果？
肠道菌群的作用
肠道菌群参与膳食成分分解与代谢，可产生短链脂肪酸等物质，并与肠道屏障、免疫调节和糖代谢有关。菌群组成改变不等同于菌群功能一定变差，更不等同于已经发生疾病。
2022年《Cell》人体试验（原稿演讲备注）
项目	研究信息
研究对象	120名健康成年人
研究条件	糖精、三氯蔗糖、阿斯巴甜、甜菊糖苷及两种对照条件
干预时间	约两周
摄入剂量	低于相应ADI
检测指标	肠道菌群、葡萄糖耐量等
主要发现	不同甜味剂的影响存在个体差异；糖精与三氯蔗糖组观察到葡萄糖耐量变化
局限	干预时间较短、样本有限，不能直接外推到所有代糖及长期慢性疾病结局


原稿讨论的潜在后果
- 食欲与饮食行为： 原稿讨论肠道菌群与大脑之间的信号联系，并推测菌群变化可能影响饱腹感、甜食或高热量食物的渴望，进而影响能量摄入。
- 胃肠道耐受： 原稿提到木糖醇、赤藓糖醇等糖醇与腹胀、排气、腹泻等不适，以及不同人的耐受差异。
原稿待核实：页面将菌群变化直接描述为更馋、更容易吃多和长胖，所引《Cell》短期研究不足以证明这些长期结果。原稿也将赤藓糖醇与其他糖醇统一解释为肠道细菌发酵产气，且将无糖气泡水引起的不适一概归于糖醇；这两种归因需要按具体成分、吸收代谢特点及剂量另行核实。

核心结论： 部分甜味剂可能影响菌群或代谢反应，但不能据此断定长期饮用无糖饮料会导致糖尿病、肥胖或其他疾病。

原稿来源： 《Cell》，2022年，DOI：10.1016/j.cell.2022.07.016。

<a id="chapter-6"></a>
第六章｜理性的选择
<a id="p21"></a>
第21页｜0糖、0蔗糖、0卡，到底应该怎么选？
以原PPT引用的GB 28050—2011营养标签标准为依据，三种标示所关注的指标并不相同。
标示	关注指标	原PPT给出的标准或含义	常见误区
0糖 / 无糖	糖含量	每100 g或100 mL糖不超过0.5 g	不代表绝对没有任何糖
0蔗糖	蔗糖这一种糖	不含蔗糖不等于没有其他糖	可能仍含果糖、葡萄糖或果葡糖浆
0卡 / 无能量	能量	每100 mL能量不超过17 kJ，约4千卡	不代表数学意义上的绝对零热量


案例一：无糖饮料。 500 mL饮料若每100 mL含糖0.5 g，则整瓶含糖2.5 g；按每100 mL计算的无糖声称门槛不能直接理解为整瓶绝对无糖。

案例二：0蔗糖食品。 原PPT展示标注“0蔗糖”但配料表中含结晶果糖（>5%）的标签，说明没有蔗糖不代表没有其他糖来源。

案例三：无糖奶茶。 现制奶茶的“无糖”选项不能直接等同于预包装食品的无糖营养声称。牛奶、奶盖、珍珠等配料仍可能提供能量。
选购方法
1. 查看配料表，了解糖及甜味剂的来源。
2. 查看营养成分表，关注糖（如有列出）与能量等指标。
3. 按实际饮用容量换算，不只看每100 mL的数据。
核心结论： 0糖看糖含量，0卡看能量，0蔗糖还需要核查其他糖来源。

原稿来源： GB 28050—2011；GB 28050—2025（原稿注明已发布，将于2027年3月16日实施）。标准适用状态以原PPT制作时间为背景，后续更新文档时应重新核对。

<a id="p22"></a>
第22页｜每天喝无糖饮料，真的没有问题吗？
核心问题	回答
每天喝无糖可乐会瘦吗？	不一定。替代原本的含糖饮料可能减少糖与能量；整体能量摄入未减少时，不保证减重。
无糖饮料可以随便喝吗？	不建议无限量饮用，还需考虑甜味剂摄入量、饮料酸度、咖啡因、个人耐受及是否替代日常饮水。
代糖是坏东西吗？	代糖不是单一物质，不同甜味剂的安全性、代谢方式与证据不同；符合食品安全要求也不意味着可以无限量摄入。


日常选择
使用场景	建议
日常补水	优先白水，也可选择适合自己的无糖茶
原本经常喝含糖饮料	可以考虑将其中一部分替换为无糖版本
偶尔想喝甜饮料	结合整体饮食与摄入量适当安排


最终结论： 代糖是一种减少糖摄入的工具，不是一种健康保证。少一点糖，多一点选择。真正值得管理的是长期饮食习惯，而不只是包装上的一个“0”。
